# Architecture

```text
                         ┌──────────────────┐
                         │     Browser      │
                         └────────┬─────────┘
                                  │
                                  ▼
                         ┌──────────────────┐
                         │   Astro SSR      │
                         │   Svelte UI      │
                         └───────┬──────────┘
                                 │
                ┌────────────────┼────────────────┐
                ▼                ▼                ▼
        Better Auth        Astro API          Blog pages
                └────────────────┬────────────────┘
                                 ▼
                           Drizzle ORM
                                 ▼
                          Neon PostgreSQL
```

This documentation site is a separate Bun workspace (`@blgrspt/docs` in `website/`). It does not share the Astro runtime.
